# MATH Dataset

MATH는 경시대회 수준의 수학 문제 12,500개로 구성된 고난도 수학 추론 Benchmark입니다.
GSM8K보다 복잡한 대수·기하·정수론·확률 문제를 다루며, 각 문항에 단계별 해설이 포함됩니다.

## 기본 정보

| 항목 | 내용 |
| --- | --- |
| 정식 명칭 | Measuring Mathematical Problem Solving With the MATH Dataset |
| 발표 | Hendrycks et al., NeurIPS 2021 |
| 규모 | 12,500개 문제 |
| 구성 | algebra, counting and probability, geometry, intermediate algebra, number theory, prealgebra, precalculus |
| 난이도 | 각 문항에 Level 1~5 난이도 레이블 |
| 대표 지표 | 최종 답 정확도, 분야·난이도별 정확도 |
| 자료 | [논문](https://arxiv.org/abs/2103.03874), [공식 저장소](https://github.com/hendrycks/math) |

## 1. 소개

MATH는 단순 산술이 아니라 여러 개념을 조합해야 하는 경시대회 문제를 통해 모델의 수학적 문제 해결을 측정합니다.
문항에는 정답과 전체 풀이가 함께 제공되어 모델의 설명 생성, 과정 감독, 검증기 학습에 활용할 수 있습니다.

문제 유형과 난이도가 넓어 모델이 어떤 수학 분야에서 무너지는지 확인하기 좋습니다.
원 논문은 모델 규모만 키우는 방식으로는 MATH 성능을 빠르게 높이기 어렵다고 분석했습니다.

## 2. 평가 내용

MATH는 일곱 개 분야와 다섯 개 난이도 수준으로 문항을 나눕니다.

- Algebra
- Counting and Probability
- Geometry
- Intermediate Algebra
- Number Theory
- Prealgebra
- Precalculus

각 문항은 문제 설명, 정답, 단계별 해설, 난이도와 분야 정보를 가집니다.
정답은 숫자, 식, 분수, 집합, 좌표, LaTeX 표현 등 다양한 형식으로 나타납니다.

따라서 채점기는 문자열을 그대로 비교하지 않고 정답을 추출하고 정규화해야 합니다.
일부 평가 하네스는 최종 `\boxed{}` 표현을 읽거나 수식 동치성을 검사합니다.
수식 동치성 검사의 허용 범위와 실패 사례를 결과와 함께 기록해야 합니다.

## 3. 평가 수행 방법

### 3.1 데이터와 prompt

일반적인 평가는 test split을 사용하고, train split의 풀이를 few-shot 예시나 학습 데이터로 사용할 수 있습니다.
평가 데이터가 학습에 노출되지 않았는지 확인하기 위해 데이터 버전과 모델 학습 범위를 기록합니다.

모델에 단계별 풀이를 요구할 때는 “정답만”을 요구하는 설정과 분리합니다.
풀이를 생성하게 하면 정답 정확도 외에 과정의 타당성을 사람이 검토하거나 자동 검증할 수 있습니다.

### 3.2 정답 추출과 정규화

권장 채점 순서는 다음과 같습니다.

1. 모델 출력에서 최종 답 후보를 추출합니다.
2. `\boxed{...}`, 달러 기호, 쉼표, 공백, 불필요한 문장을 정규화합니다.
3. 숫자·분수·식 표현을 가능한 경우 수학적으로 비교합니다.
4. 표현이 모호하거나 파싱에 실패한 사례를 별도 오류로 기록합니다.
5. 원 정답과 비교해 문항별 정답 여부를 계산합니다.

수식 동치성 도구를 사용할 때는 허용된 함수, 변수, 부동소수점 오차, LaTeX 명령을 고정합니다.
정답 추출기가 너무 관대하면 틀린 답을 정답으로 만들고, 너무 엄격하면 같은 수학적 답을 오답으로 만들 수 있습니다.

### 3.3 보고할 지표

전체 정확도만 보고하지 않고 다음을 함께 봅니다.

- 7개 분야별 정확도
- Level 1~5별 정확도
- 정답 추출 실패율
- 풀이가 있지만 최종 답이 틀린 비율
- 반복 샘플링 또는 verifier 사용 전후의 변화
- 평가 시간과 토큰 비용

## 4. 결과 해석과 한계

MATH는 수학 추론을 깊게 측정하지만, 실제 업무에서 필요한 계산기 사용, 표·코드·검색 도구와의 결합은 기본 평가에 포함되지 않습니다.
문제가 공개되어 있어 최신 모델의 학습 데이터와 중복될 수 있고, 난이도별 표본 수 차이도 점수 분산에 영향을 줍니다.

정답 정확도만으로 풀이의 신뢰성을 판단하지 않습니다.
모델이 정답을 맞혀도 잘못된 논리를 제시할 수 있고, 반대로 풀이가 타당하지만 정답 추출 형식 때문에 오답 처리될 수 있습니다.
고위험 수학·과학 애플리케이션에서는 계산기, 기호 계산기, 독립 검증기, 사람 검토를 결합해야 합니다.

GSM8K와의 차이는 난이도와 문항 형식입니다.
GSM8K는 일상적인 초등 수학 문장제와 짧은 산술 연쇄에 초점을 두고, MATH는 경시대회 수준의 추상적이고 긴 풀이를 포함합니다.
두 점수를 평균내어 하나의 “수학 지능” 점수로 만드는 대신, 난이도별 프로파일로 제시하는 편이 해석에 적합합니다.
